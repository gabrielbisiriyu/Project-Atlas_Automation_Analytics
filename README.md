# Project Atlas Automation & Network Analytics

## Overview

A collection of Python-based network automation, data collection, analysis, and operational tooling built around **Project Atlas**, a simulated enterprise network environment.

The projects use Project Atlas as a **data source and reference environment**, collecting real operational data from its Cisco devices and Ubuntu infrastructure to demonstrate practical network engineering, automation, monitoring, and analytics workflows.

**Project Atlas:** [Project Atlas on GitHub](https://github.com/gabrielbisiriyu/EVE-NG_Projects-/tree/main/project-atlas)

---

## Relationship with Project Atlas

**Project Atlas → Network infrastructure and data source**

**This repository → Automation, data collection, analysis, and reporting**

The two repositories are intentionally separated:

* **Project Atlas** contains the EVE-NG enterprise network, Cisco configurations, Ubuntu services, security, and infrastructure automation.
* **This repository** uses that environment as a source of operational data for Python-based network engineering projects.


---

## Projects

### Project 1 — Network Inventory & Configuration Compliance

Collects operational and configuration data from Atlas Cisco devices using Netmiko, parses the results with Pandas, and evaluates devices against a defined configuration baseline.

**Focus:** Network inventory, configuration compliance, operational data collection.

### Project 2 — Syslog Analysis & Anomaly Detection

Analyzes centralized network syslog data generated by Project Atlas to identify event patterns, errors, authentication failures, and unusual activity.

**Focus:** Network operations, log analysis, anomaly detection.

### Project 3 — OSPF Topology & Route Analysis

Collects OSPF and routing information from Atlas devices and analyzes network topology, routing relationships, and redundancy.

**Focus:** Routing analysis, topology visualization, network resilience.

### Project 4 — Network Capacity Planning

Collects interface utilization data over time and analyzes traffic trends to support capacity planning and forecasting.

**Focus:** Performance analysis, time-series data, capacity planning.

### Project 5 — Configuration Drift Detection

Compares current Atlas device configurations against known-good configurations to identify unexpected changes.

**Focus:** Configuration management, compliance, operational automation.
