# Project 2 — Syslog Analysis & Anomaly Detection

## Overview

This project analyzes real syslog data generated by the **[Project Atlas](https://github.com/gabrielbisiriyu/EVE-NG_Projects-/tree/main/project-atlas) enterprise network** enterprise network.

Project Atlas Cisco devices send syslog messages to an Ubuntu-based centralized syslog server. The collected logs are then copied to the analysis environment, parsed into structured data, and analyzed using Python and Pandas.

The goal is to turn raw network syslog messages into useful operational information such as configuration changes, network events, OSPF adjacency changes, event severity, and event volume.


## Data Source

The syslog data comes from the Project Atlas network environment.

The centralized syslog server stores device-specific logs under:

```text
/var/log/network/
```


## Analysis Notebook

The main analysis and visualisation work is documented in:

**[01_syslog.ipynb](notebooks/01_syslog.ipynb)**

The notebook contains the exploratory and operational analysis performed against the parsed syslog dataset.

## Analysis Performed

### 1. Syslog Event Parsing

Raw Cisco syslog messages are parsed into structured fields using Python regular expressions and Pandas.

The parser identifies fields including:

```text
timestamp
device
sequence
device_timestamp
facility
severity
mnemonic
message
event_type
username
source_ip
```

Additional OSPF-specific fields are extracted when an OSPF adjacency event is detected.

### 2. Event Classification

Syslog messages are classified into operational event types, including:

* Configuration changes
* OSPF adjacency changes
* Interface-related events
* Other events

The classification provides a more useful structure for subsequent analysis.


### 3. Event Volume Analysis

The dataset is also examined for changes in event volume over time.

This provides a basic operational view of periods where a device or the network generated unusually high numbers of syslog messages.

```text

      ↓
Cisco Syslog
      ↓
Centralized syslog Server
      ↓
Raw Log Collection
      ↓
Python Parsing
      ↓
Structured Data
      ↓

      ↓
```

The project uses real syslog data generated by the Project Atlas lab rather than a synthetic dataset.
